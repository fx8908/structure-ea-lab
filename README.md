# USDJPY Structure Lab LP

スマホ優先の、静的HTML 1ページ構成です。`index.html` と `assets` フォルダをそのままGitHubへアップロードすれば使えます。

## 公開前に必ず変更する場所

1. `index.html` 内の `class="cta payment-link"` を検索する
2. 現在設定されている `https://buy.stripe.com/test_...` を、本番審査後に発行した本番Payment Linkへ変更する
3. ボタン文言の「テスト決済へ進む」と、直後のサンドボックス注意書きを本番用へ変更する
4. 商品の正式名称、税込価格、納品物、サポート範囲、返品条件を確定する
5. 販売者情報・特定商取引法に基づく表記・プライバシーポリシーへのリンクを追加する

## GitHub Pagesで無料公開

1. GitHubで公開リポジトリを作る
2. このフォルダ内の `index.html` と `assets` をリポジトリ直下へアップロードする
3. リポジトリの **Settings → Pages** を開く
4. **Deploy from a branch**、ブランチ **main**、フォルダ **/(root)** を選んで保存する

## ページ内の表現について

- 添付チャートは「市場スナップショット」であり、EAの取引実績とは表示していません。
- 現行版は取引サンプルが少ないため、「完成版」「高勝率」「稼げる」等の表現は避けています。
- リスク数値は、添付されたV14 / V6資料の現行基準に合わせています。
